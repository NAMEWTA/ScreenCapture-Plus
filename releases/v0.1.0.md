# huhucapture v0.1.0

首个统一 Qt 版本面向 Windows x64 和 Linux amd64。两端共用截图编辑器、范围批注、媒体历史、设置和局域网传输界面。

- 截图、钉图、长截图、GIF 和 MP4 使用各平台的采集与编码后端。MP4 可选择系统声音与麦克风。
- 范围批注导出包含完整备注，保存和复制可将成品归档到系统文档目录下的 `huhucapture`。
- 从历史中选择一份归档媒体，可通过 LocalSend 在可达局域网内发送。接收方确认后，应用校验并归档文件。

## 下载

| 平台 | 发行包 |
| --- | --- |
| Windows x64，Windows 10 1809 及以上 | `huhucapture-v0.1.0-windows-x64-setup.exe` 或 `huhucapture-v0.1.0-windows-x64.zip` |
| Linux amd64，Ubuntu 24.04 构建基线 | `huhucapture-v0.1.0-linux-amd64.deb` 或 `huhucapture-v0.1.0-linux-amd64.AppImage` |

Windows 便携 ZIP 需完整解压到新目录后运行。已有便携 `config.json` 可复制到新 EXE 同目录，建议保留原件。Windows v0.0.6 可以从关于页下载完整 ZIP。使用 v0.0.5 或更早版本时，请从发行页面直接选择完整安装包。Windows 10 1803 可继续使用 [v0.0.6](https://github.com/NAMEWTA/huhucapture/releases/tag/v0.0.6)。

Linux Wayland 的截图、录制、快捷键和窗口行为取决于当前桌面提供的 Portal 能力及用户授权。有关包校验、对应源码和调试符号，见 [打包与发行说明](https://github.com/NAMEWTA/huhucapture/blob/v0.1.0/docs/qt-packaging.md)。

发行验证覆盖自动化与受控平台环境。实体双屏混合 DPI、物理音源、系统输入法、实体设备互传及各桌面组合的人工验收另行记录。
