# huhucapture v0.0.1

huhucapture 的首个公开版本：一个原生 Windows 截图、批注与录屏工具，把截图中的范围和文字说明整理成可以直接保存、复制的一张图片。

## 范围批注

截图后进入编辑窗口，选择普通“序号”旁的“批注”，按住左键拖出矩形。边框与左上角小编号自动使用相同主题色，松开后即可在右侧输入多行说明。

支持任意方向拖框、拖动边框或编号整体移动、八个控制点调整范围。矩形保持在原图内，单击与过小误拖不留下空框；透明内部仍可添加其他标记或嵌套批注。编号、颜色和文字保持绑定，删除其他项不会重新编号。

保存和复制会将原图、图内标记与完整说明合并。文字自动换行，字号和间距按空间收紧，必要时增加高度或右侧列数，原图像素保持不变。无法在设备尺寸或内存预算内容纳完整内容时，提示失败并保留编辑状态。

## 截图、编辑与录屏

- 44 × 44 逻辑像素工具按钮、24 逻辑像素图标，适配 DPI 并在窄工作区换行。
- 区域截图、钉图、取色、长截图，以及矩形、椭圆、箭头、普通序号、线条、文字、马赛克和橡皮擦。
- GIF / MP4 录屏，MP4 可选择系统声音与麦克风。
- 二维码识别、托盘、用完即走、命令行、便携配置和多语言。
- 不包含 OCR 或外部文字识别插件。

## 统一的 huhucapture 身份

程序、配置目录、发布包与更新源统一使用 `huhucapture`，视觉采用 huhu 家族虎虎形象和截图范围角标。项目由 [NAMEWTA](https://github.com/NAMEWTA) 维护。

默认配置为 `%appdata%\huhucapture\config.json`；EXE 同目录已有 `config.json` 时优先使用便携配置。简体中文和英语内置，便携包包含额外语言。详细使用方式见 [项目首页](https://github.com/NAMEWTA/huhucapture#readme)。

## 下载

支持 **Windows 10 1803 及以上，x64**，无需安装。可选择单文件或完整便携包：

| 文件 | 内容 |
| --- | --- |
| `huhucapture.exe` | 可直接运行的单文件程序 |
| `huhucapture-v0.0.1-windows-x64.zip` | 程序、语言、许可和构建信息 |
| `huhucapture-v0.0.1-windows-x64-symbols.zip` | 问题定位符号 |
| `build-info.json` | 源提交、版本、架构、工具链、依赖与 EXE 哈希 |
| `SHA256SUMS.txt` | 下载校验 |

Windows 文件版本为 **0.0.1.0**。替换已运行的程序前请先退出进程，再启动新文件。

本次版本序列从 `v0.0.1` 开始，使用此前开发构建的用户需手动下载替换。先在旧程序中关闭开机自启动，再完全退出并运行新程序。配置不会自动迁移；需要沿用时，可将原 `config.json` 复制到 `%appdata%\huhucapture\config.json`，或放在新 EXE 同目录使用便携配置。

## 构建与验证

发布流程要求 x64 Release / Debug、八个核心程序、PowerShell 语法、真实 DirectWrite / Direct2D / WIC 导出、独立 EXE 启动、正式窗口 / 剪贴板集成和打包检查全部通过，再上传资产。

具体结果见 [Windows Actions](https://github.com/NAMEWTA/huhucapture/actions/workflows/windows.yml)。脚本 GUI 不替代物理输入、IME、混合 DPI、显卡和音频硬件的人工验收，覆盖范围见 [验证指南](https://github.com/NAMEWTA/huhucapture/blob/main/docs/validation.md)。代码和分发依赖遵循仓库中的 MIT 许可及第三方许可声明。
