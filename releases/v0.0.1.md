# ScreenCapture-Plus v0.0.1

这是 ScreenCapture-Plus 独立版本线的第一个版本，基于 ScreenCapture 原生 Windows 截图工具继续维护。

## 新增编号批注

截图进入图像标记窗口后，选择“标号”旁的“批注”工具，在图片上点击添加编号。右侧批注表按编号对应，点击图中编号或列表条目即可编辑；编号可以拖动，支持删除、撤销和重做。

颜色按编号自动分配，前几项使用蓝、琥珀、青绿、紫等主题色，后续继续生成不同色相。已有编号的颜色不会随其他条目的删除而改变。

点击保存或复制时，原图、图内标记和全部批注合成一张图片。正文与行距自动压缩到可读下限，内容更多时扩展画布高度或右侧列数，保留全部文字；原图按原始像素输出，不受编辑窗口缩放影响。

## 更易操作的工具栏

各工具栏采用 44×44 逻辑像素点击区和 24 逻辑像素图标。窄屏会换行，图标和点击区保持大小，按所在显示器的工作区定位。

## 功能整理

移除文字识别及其插件下载、进程启动和专用命令行入口。二维码识别、截图、取色、普通标号、文本/图形标记、长截图、GIF/MP4、托盘及其他既有入口继续保留。

## 下载与验证

- `ScreenCapture.exe`：单 EXE 入口。
- `ScreenCapture-Plus-v0.0.1-windows-x64.zip`：EXE、额外语言和依赖许可。
- `ScreenCapture-Plus-v0.0.1-windows-x64-symbols.zip`：故障定位符号。
- `SHA256SUMS.txt`、`build-info.json`：下载校验及源提交/依赖信息。

本版本发布任务要求 Windows Release、Debug、核心回归、原生合成/PNG 检查、独立 EXE 启动及打包检查全部成功。多屏/DPI、输入法、真实显卡和音频设备的人工验收清单在仓库 `docs/VALIDATION.md`；原生离屏渲染检查不等同于全部 GUI 验收。

若使用的是先前带上游 2.x 版本号的开发构建，请先退出旧程序，再手动下载替换一次。本项目从 0.0.1 开始独立编号。
