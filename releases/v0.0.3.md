# huhucapture v0.0.3

本次补丁集中改善设置窗口的整体比例、文字层级、对齐，以及语言下拉框的视觉和操作一致性。Windows 文件版本为 **0.0.3.0**。

## 更协调的桌面设置

- 默认窗口调整为 **720 × 500 逻辑像素**，侧栏宽 160，内容列在可用空间内居中；三个页面统一标题、卡片和行内操作的对齐。
- 正文采用 14px，辅助说明 12px，标题 22px，主要控件高度 32px。同步调整行高、圆角和留白，避免只改变字号而留下比例失衡。
- 保持浅灰画布、白色内容分组和单一蓝色交互，按系统 DPI 一致缩放；较小工作区约束窗口与内容尺寸。

## 统一语言选择体验

- 下拉触发器和弹层共用字体、间距与状态，语言文字和箭头分别布局，当前语言有勾选标识。
- 方向键移动高亮，Enter 或点击提交；Esc 和点击外部取消展开，不改变当前语言。
- 弹层按可用屏幕空间定位，处理列表滚动与命中；页面切换、窗口关闭和 DPI 变化遵守所属窗口的生命周期。
- “获取更多语言”作为独立操作与语言值区分。

设计依据与扩展约束见 [界面设计文档](https://github.com/NAMEWTA/huhucapture/blob/main/docs/design.md)，包括 Apple HIG、Fluent 2 和 WinUI Gallery 的具体参考。

## 验证范围

发布流程要求本次提交通过 Windows Release / Debug、核心回归、原生渲染、启动、真实窗口/剪贴板及打包检查。执行结果以对应提交的 [Windows Actions](https://github.com/NAMEWTA/huhucapture/actions/workflows/windows.yml) 为准。

设置页验收同时关注 100% / 125% / 150% 比例、展开弹层、键盘提交与取消、指针命中及窗口生命周期。受控比例的原生截图与真实混合 DPI 多屏验收分别记录，不能用图片缩放替代窗口渲染。完整边界见 [验证指南](https://github.com/NAMEWTA/huhucapture/blob/main/docs/validation.md)。
