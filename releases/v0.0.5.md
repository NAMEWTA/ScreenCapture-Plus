# huhucapture v0.0.5

本次补丁改进更新下载入口，并修复剪切复制板跨不同 DPI 显示器拖动时被错误中断的问题。Windows 文件版本为 **0.0.5.0**。

## 最新版本下载到系统 Downloads

- 在“设置 → 关于”点击“下载最新版本”，直接在后台取得本仓库最新稳定 Release 的 EXE；即使当前已经是同版本，也可以再次下载。
- 文件保存到 Windows 系统“下载”目录，遵循用户移动或重定向后的实际位置。界面提供进度、最终文件位置和打开下载文件夹的操作。
- 本地文件按 `huhucapture-<tag>-windows-x64.exe` 命名，重名使用新后缀，保留已有文件。
- 校验发行大小、SHA256 后写入独有临时文件，再核对 EXE 版本，全部成功才提交成品；网络或保存失败可重试。
- 每日新版本检查仍保留，用户确认后使用同一下载流程。下载不会自动替换运行中的程序、执行新版或重启应用；完成后先退出旧程序，将下载文件改成原程序的文件名，再替换日常使用的 EXE 并重新启动。

文件保护、线程与失败约束见 [更新下载说明](https://github.com/NAMEWTA/huhucapture/blob/main/docs/updates.md)。

## 修复跨屏拖动闪跳

剪切复制板原有 DPI 回调会在捕获 HWND 为当前窗口时直接释放鼠标捕获，但 Windows 的标题栏拖动也使用该窗口的捕获。这会在跨不同 DPI 的显示器时打断原生移动循环。

本版本区分列表按钮/滚动条的客户端捕获与系统窗口移动/缩放捕获；DPI 改变、失焦、刷新和翻页只取消应用拥有的客户端交互。系统提供的目标位置和尺寸继续由窗口框架应用，初次打开时的居中不参与拖动过程。捕获丢失后也不会继续执行旧的按钮按压动作。

窗口位置、捕获与 DPI 的维护约束见 [界面设计](https://github.com/NAMEWTA/huhucapture/blob/main/docs/design.md)。

## 下载

| 文件 | 用途 |
| --- | --- |
| `huhucapture.exe` | 可直接运行的 Windows x64 单文件程序 |
| `huhucapture-v0.0.5-windows-x64.zip` | 同一程序、额外语言、许可和构建信息 |
| `huhucapture-v0.0.5-windows-x64-symbols.zip` | 与本次 EXE 配套的 PDB 调试符号 |
| `build-info.json` | 版本、源提交、工具链、依赖和 EXE SHA256 |
| `SHA256SUMS.txt` | 发行文件校验值 |

普通使用下载 EXE 或便携 ZIP 即可。符号包用于开发与故障定位，必须搭配同一次构建的 EXE。产物说明与校验方法见 [README](https://github.com/NAMEWTA/huhucapture#下载与运行)。

## 验证范围

发布流程要求本次提交通过 Windows Release / Debug、核心回归、原生渲染、启动、真实窗口/剪贴板、真实更新下载及打包检查。实际执行结果以对应提交的 [Windows Actions](https://github.com/NAMEWTA/huhucapture/actions/workflows/windows.yml) 与 [验证指南](https://github.com/NAMEWTA/huhucapture/blob/main/docs/validation.md) 所列证据为准。

更新下载模式通过正式关于页访问测试当时的最新稳定 Release，并验证系统 Downloads 的成品与完成状态。受控 DPI 消息回归检查捕获所有权和建议矩形；它不代表实体双屏连续拖动已经完成人工验收。未执行的混合 DPI、重定向目录及网络故障组合仍需单独记录。
