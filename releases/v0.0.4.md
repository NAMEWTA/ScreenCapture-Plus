# huhucapture v0.0.4

本次补丁集中调整剪切复制板的按钮、列表密度、字体与对齐，并补齐上游致谢和来源记录。Windows 文件版本为 **0.0.4.0**。

## 更紧凑的剪切复制板

- 默认窗口调整为 760 × 560 逻辑像素，尺寸受当前显示器工作区约束。
- 预览、文件名和时间/大小信息构成稳定的列表主体；复制、定位和翻页采用 32px 高的桌面按钮，正文与辅助文字沿用设置页的比例。
- 行内操作采用中性色轻按钮，并按本地化文字分配宽度；只有多页内容时才展示分页操作。
- 缩略图保持媒体比例，长文字按可用宽度省略；绘制、滚动和点击共享布局，正文与省略号随同一 DPI 缩放。
- 保持 Documents 归档、图片/媒体文件复制分流、视频封面和回收站确认的现有业务边界。

布局与扩展约束见 [界面设计](https://github.com/NAMEWTA/huhucapture/blob/main/docs/design.md)，持久化与清理语义见 [媒体历史](https://github.com/NAMEWTA/huhucapture/blob/main/docs/media-history.md)。

## 下载

| 文件 | 用途 |
| --- | --- |
| `huhucapture.exe` | 可直接运行的 Windows x64 单文件程序 |
| `huhucapture-v0.0.4-windows-x64.zip` | 同一程序、额外语言、许可和构建信息 |
| `huhucapture-v0.0.4-windows-x64-symbols.zip` | 与本次 EXE 配套的 PDB 调试符号 |
| `build-info.json` | 版本、源提交、工具链、依赖和 EXE SHA256 |
| `SHA256SUMS.txt` | 发行文件校验值 |

普通使用下载 EXE 或便携 ZIP 即可。手动更新前退出正在运行的程序，再替换文件；符号包用于开发与故障定位。各项产物和校验方式见 [README](https://github.com/NAMEWTA/huhucapture#下载与运行)。

## 验证范围

发布流程要求本次提交通过 Windows Release / Debug、核心回归、原生渲染、启动、真实窗口/剪贴板及打包检查。执行结果以对应提交的 [Windows Actions](https://github.com/NAMEWTA/huhucapture/actions/workflows/windows.yml) 为准。

媒体历史验收关注 100% / 125% / 150% 比例、中英文按钮、真实图片与视频封面，以及尺寸改变和滚动后的命中。受控 DPI 消息产生的原生截图与实体多显示器人工验收分别记录。完整范围与证据索引见 [验证指南](https://github.com/NAMEWTA/huhucapture/blob/main/docs/validation.md)。
