# huhucapture v0.0.2

这次更新让保存和复制的截图、录屏成为可长期找回的本地历史，并重新整理设置页的视觉和交互。Windows 文件版本为 **0.0.2.0**。

## F1 截图

默认全局截图快捷键为 **F1**。旧配置仍使用默认 `Ctrl+Alt+A` 时迁移到 F1，其他自定义快捷键保留；可以继续在设置中修改。

## 本地媒体归档与剪切复制板

- 点击保存或完成复制后，截图、批注合图、长截图以及 GIF / MP4 自动归档到系统“文档”目录下的 `huhucapture`，支持 Windows 文档目录重定向。
- 文件使用 `YYYYMMDD-HHMMSS.ext`，同秒同类型保存追加 `-001`、`-002`，避免覆盖旧内容。
- 截图工具条的二维码识别右侧和托盘菜单新增 **剪切复制板**，以列表展示截图缩略图和视频封面；历史跨重启保留。
- 每项可再次复制或打开所在文件夹。图片复制为图像，录屏复制为稳定的媒体文件，后续录制不会覆盖先前复制的临时路径。
- 另存为默认从归档目录开始，选其他位置时保留归档副本；完成的录屏在取消另存为后仍可找回。
- 一键清除先确认，默认把当前归档媒体送入系统回收站；Windows 无法回收时会再次提示确认。它不递归清理子目录或无关文件，也不删除另存位置的副本；失败或取消后保留剩余项并刷新列表。
- 归档失败保留编辑内容或录屏临时结果，封面加载失败不影响其他条目的基本操作。

## 设置页重新设计

根据指定的 [Apple 设计规范](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/DESIGN.md) 调整通用、快捷键和关于页面：中性浅灰画布、白色内容分组、清晰深色文字与单一交互蓝，扩大字号、统一控件尺寸和留白，增加归档目录说明及打开操作。

## 文档和发行文件

维护文档集中在全小写的 `docs/` 路径，补充目录职责、架构取舍、扩展与编码约束、媒体保存/清理语义以及 UI 和验证边界。语言和品牌说明合并到对应主题文档。

PDB 符号包保留，用于开发者定位发行版崩溃。README 说明了每种资产的用途、校验步骤，以及符号必须与 EXE 来自同一次构建的要求。

| 下载文件 | 用途 |
| --- | --- |
| `huhucapture.exe` | 日常使用的单文件程序，无需安装 |
| `huhucapture-v0.0.2-windows-x64.zip` | 同一程序、额外语言、许可/声明和构建信息 |
| `huhucapture-v0.0.2-windows-x64-symbols.zip` | 同构建 PDB 调试符号；普通使用无需下载 |
| `build-info.json` | 源提交、版本、架构、工具链、依赖和 EXE SHA256 |
| `SHA256SUMS.txt` | 上述文件的下载校验 |

GitHub 自动提供的 Source code ZIP / tar.gz 是源码快照，不含可直接运行的构建产物。普通用户下载 EXE 或便携 ZIP 即可。详细说明见 [项目 README](https://github.com/NAMEWTA/huhucapture#下载与运行)。

## 更新与验证

支持 **Windows 10 1803 及以上，x64**。手动更新前先退出正在运行的 huhucapture，再替换程序；已有配置继续使用。媒体原件独立保存在文档目录下，不放在程序目录或更新临时目录中。

声明发布依赖完整 Windows 构建、核心回归、原生渲染、独立 EXE 启动、真实窗口/剪贴板和打包检查。实际结果见本版本对应的 [Windows Actions](https://github.com/NAMEWTA/huhucapture/actions/workflows/windows.yml)；物理输入、IME、混合 DPI、显卡与音频设备的覆盖边界见 [验证指南](https://github.com/NAMEWTA/huhucapture/blob/main/docs/validation.md)。
