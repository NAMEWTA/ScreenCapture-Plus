# huhucapture

**huhucapture** — нативное приложение Windows для снимков экрана, аннотаций и записи видео, которое поддерживает [NAMEWTA](https://github.com/NAMEWTA). Оно сохраняет выделенные области и пояснения к ним в одном изображении, а также поддерживает закрепление изображений, длинные снимки с прокруткой, GIF / MP4 и распознавание QR-кодов.

Проект входит в семейство [huhu](https://github.com/NAMEWTA/huhu). Фирменный персонаж и угловые метки захвата образуют его знак; файлы и правила использования описаны в [руководстве по бренду](brand.md).

## Область и пояснение в одном изображении

![Пример изображения с пронумерованными областями и пояснениями](banner.png)

Пример получен копированием из редактора приложения. Рамка, небольшой номер в её левом верхнем углу и соответствующая запись справа имеют одинаковый автоматически выбранный цвет. Удаление одной аннотации не меняет номера и цвета остальных, поэтому в нумерации возможны пропуски.

1. Выделите область экрана и откройте редактор либо удерживайте `Ctrl` при завершении выделения.
2. Выберите **Аннотацию** рядом с обычным инструментом нумерации.
3. Удерживая левую кнопку мыши, нарисуйте прямоугольник в любом направлении. После отпускания кнопки введите многострочное пояснение справа.
4. Нажмите на номер, рамку или запись в списке, чтобы изменить текст. Перетаскивайте номер или рамку для перемещения области, а маркеры по краям — для изменения размера.
5. Сохраните или скопируйте результат: исходное изображение, рисунки, области и полные пояснения будут объединены.

Слишком маленькие случайные выделения не создают аннотаций. Внутри прозрачной рамки можно рисовать и создавать вложенные области. Сворачивание панели не исключает пояснения из экспорта. Номера и цвета сохраняются при отмене, повторе и удалении других записей.

При экспорте текст переносится, а размер шрифта и интервалы уменьшаются по мере необходимости. Затем может увеличиваться высота холста или число столбцов справа. Пиксели исходного изображения сохраняются. Если полный результат превышает ограничения устройства или памяти, приложение сообщает об ошибке и сохраняет сеанс редактирования; текст не обрезается незаметно. Подробнее: [аннотации и экспорт](annotations.md).

## Возможности

- Снимки области экрана, пипетка, закрепление и масштабирование изображений, длинные снимки с прокруткой.
- Запись GIF / MP4; для MP4 доступны системный звук и микрофон.
- Прямоугольник, эллипс, стрелка, обычная нумерация, линия, текст, мозаика и ластик.
- Прямоугольные аннотации с автоматическими цветами и стабильными номерами.
- Распознавание QR-кодов и копирование их содержимого.
- Значок в трее, однократный захват, переносимые настройки и несколько языков.

Кнопки панелей имеют область нажатия **44 × 44 логических пикселя** и значки **24 логических пикселя**. Интерфейс учитывает DPI и переносит кнопки при недостатке места. OCR в приложении отсутствует.

## История снимков и записей

Сохранение или завершение копирования автоматически оставляет снимок, изображение с аннотациями, длинный снимок, GIF или MP4 в папке `huhucapture` внутри системных «Документов». Путь учитывает перенаправление папки. Имя использует местное время: `YYYYMMDD-HHMMSS.ext`; совпадения в одну секунду получают суффиксы `-001`, `-002` без перезаписи.

Кнопка истории находится справа от распознавания QR в панели захвата. Список показывает миниатюры изображений и обложки видео; можно повторно скопировать элемент или открыть его папку. История сохраняется после перезапуска. Отмена «Сохранить как» не удаляет завершённую запись, а сохранение в другой каталог оставляет архивную копию.

Историю также можно открыть из меню в трее. Очистка запрашивает подтверждение и по умолчанию перемещает перечисленные медиафайлы в корзину. Если это невозможно, Windows дополнительно спрашивает о постоянном удалении. Посторонние файлы, вложенные папки и копии в других каталогах не затрагиваются. После ошибки или отмены список оставшихся элементов обновляется.

Настройки переработаны с нейтральным фоном, белыми группами, крупным читаемым текстом и единым синим акцентом по указанному [дизайну Apple](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/DESIGN.md).

## Загрузка и запуск

Нужна **Windows 10 версии 1803 или новее, x64**. Скачайте `huhucapture.exe` в разделе [Releases](https://github.com/NAMEWTA/huhucapture/releases) и запустите его. Установка приложения и отдельная установка среды Visual C++ не требуются.

Для обычного использования достаточно EXE или переносимого ZIP.

| Файл | Назначение |
| --- | --- |
| `huhucapture.exe` | Готовая программа x64 с китайским и английским языками |
| `huhucapture-v0.0.2-windows-x64.zip` | Та же программа, дополнительные языки, лицензии и сведения о сборке |
| `huhucapture-v0.0.2-windows-x64-symbols.zip` | PDB для отладки и анализа сбоев; для запуска не нужен |
| `build-info.json` | Коммит, версия, архитектура, инструменты, зависимости и SHA256 EXE |
| `SHA256SUMS.txt` | Контрольные суммы остальных четырёх файлов выпуска |
| `Source code (zip / tar.gz)` от GitHub | Исходный код тега без готового EXE |

Для отладки распакуйте PDB **той же сборки**, что и EXE, и добавьте каталог в путь символов Visual Studio или WinDbg. Другой PDB с тем же номером версии не обязательно подходит. Для исходного кода используйте коммит из `build-info.json`. Контрольную сумму можно получить через `Get-FileHash .\huhucapture.exe -Algorithm SHA256` и сравнить с `SHA256SUMS.txt`.

Перед ручной заменой завершите приложение. Встроенное обновление запрашивает подтверждение. Клавиша захвата по умолчанию теперь **F1**: прежнее стандартное `Ctrl+Alt+A` заменяется на F1, остальные пользовательские сочетания и существующие настройки сохраняются.

| Действие | Клавиши |
| --- | --- |
| Начать захват (глобальная клавиша по умолчанию) | `F1` |
| Сохранить всё изображение | `Ctrl+S` |
| Скопировать всё изображение | `Ctrl+C`, `Enter` или двойной щелчок вне редактирования текста |
| Отменить / повторить рисунок | `Ctrl+Z` / `Ctrl+Y` вне редактирования текста |
| Ограничить форму обычной фигуры | Удерживать `Shift` при рисовании |
| Масштаб закреплённого изображения | `Ctrl` + колесо мыши |
| Скопировать RGB / HEX / CMYK | `Ctrl+R` / `Ctrl+H` / `Ctrl+K` при выборе цвета |

При вводе текста выделение, удаление и `Ctrl+C` обрабатывает поле ввода. `Ctrl+S` по-прежнему сохраняет изображение. Нажмите `Esc`, чтобы закончить ввод перед копированием изображения. Отдельного стека отмены текста у общего редактора аннотаций пока нет; `Ctrl+Z` / `Ctrl+Y` во время ввода не удаляют аннотацию целиком.

## Параметры запуска и настройки

```powershell
huhucapture.exe --auto-quit=true
huhucapture.exe --enter=pin
huhucapture.exe --enter=long
huhucapture.exe --enter=video
huhucapture.exe --enter=qr
huhucapture.exe --enter=tray
huhucapture.exe --enter=long --auto-quit=true
```

`--enter=qrcode` — другое имя для `--enter=qr`. Параметры выбирают интерактивный режим приложения.

Настройки по умолчанию: `%appdata%\huhucapture\config.json`. Если рядом с EXE уже есть `config.json`, используется он; для переносимого режима можно создать пустой файл. Дополнительные языки загружаются из каталога `Lang` рядом с EXE. Только если этого каталога нет, используется `%appdata%\huhucapture\Lang`; содержимое двух каталогов не объединяется. Упрощённый китайский и английский встроены. См. [языковые файлы](languages.md).

## Разработка

Для сборки нужны Windows x64, Visual Studio 2026 с инструментами C++ для рабочего стола, MSVC v145, ATL и Windows SDK, PowerShell 7, Git и Rustup.

```powershell
pwsh ./scripts/build.ps1 -Configuration Release
pwsh ./scripts/test.ps1
pwsh ./scripts/test-windows.ps1
pwsh ./scripts/smoke.ps1
pwsh ./scripts/test-windows.ps1 -Gui
pwsh ./scripts/package.ps1
```

Программа создаётся в `artifacts/bin/x64/Release/huhucapture.exe`; решение — `huhucapture.slnx`. Подробные руководства на китайском: [сборка и выпуск](building.md), [архитектура](architecture.md), [проверки](validation.md), [участие в разработке](../CONTRIBUTING.md). Автоматические тесты не заменяют ручную проверку ввода, IME, нескольких DPI и звука.
