# huhucapture

huhucapture — приложение для снимков экрана, аннотаций, записи и обмена файлами в Windows и Linux. Оно поддерживает закрепление снимков, длинные снимки с прокруткой, GIF / MP4, распознавание QR-кодов и передачу через LocalSend.

Для Windows x64 скачайте установщик или полный переносимый ZIP, для Linux amd64 — DEB или AppImage. Перед запуском извлеките весь Windows ZIP в новую папку. В Windows 10 1803 можно использовать переходную версию v0.0.6.
