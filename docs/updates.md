# 更新下载与迁移

在设置的关于页选择下载时，Qt 应用查询本仓库最近的稳定发行。它根据平台、架构与当前安装形态选择完整包，核对清单、构建身份、文件长度及 SHA256，再提交到系统下载目录。

更新过程和窗口生命周期分离。关闭设置后，已开始的任务继续下载。重名时使用独立文件名。应用退出会取消并等待后台任务完成清理。下载完成后提供实际文件路径，安装或解压由用户发起。

Windows v0.0.6 更新桥可下载 Qt Windows 完整便携 ZIP。收到 ZIP 后完整解压到新目录，便携用户可将原 `config.json` 复制到新程序同目录。使用更早版本的用户可从发行页手动选择完整安装器或 ZIP。
