# 共享录屏工具栏

`src/ui/qt/RecordingWindow.*` 复用截图与编辑器的工具栏布局、44 DIP 按钮、
24 DIP 图标、原有图标字体及语言目录。MP4/GIF、系统声音、麦克风、开始、
停止并保存、停止并复制、丢弃沿用原录屏语义。GIF 不携带声音；切到 GIF 时
清除两个音源，切回 MP4 不擅自恢复。

界面分别显示准备、录制、停止、编码收尾、归档与后续输出。开始按钮不代表
编码器已准备完毕；计时显示服务传入的单调时钟时长，不通过累加 GUI 定时器
次数推算。第一个停止意图固定后，后续点击或快捷键不会改成另一个结果。
归档完成与剪贴板接收确认是两个事件，等待实际输出回执期间保留原生窗口。

失败时显示完整的保留路径，并只在输出服务允许时提供重试。已经完成的文件
不因关闭界面或取消另存为而被删除。重试沿用原有字体中的可见图形；隐藏的
操作不占据工具栏位置。错误详情为可选择的纯文本，不把路径解释为 HTML。

首次位置采用调用者已核对的屏幕与逻辑选区，不对全局坐标乘一个统一 DPR。
之后语言和布局刷新只调整尺寸，不重新居中。准备阶段的 Qt 原生工具栏握柄
和录制阶段的计时区域调用 `QWindow::startSystemMove()`，由桌面负责实际跨屏
拖动和输入 serial。控件渲染测试不代替真实混合 DPI 拖动验收。

`services/desktop/CaptureExclusion` 把已有 Windows 排除规则提取为同一原生
助手。旧产品与 Qt 调用它；Windows 10 2004 之前不退回会产生黑色矩形的旧
affinity 值，成功必须由系统读回确认。Linux 返回实际不支持，不创建假能力。
工具栏可据此显示“移出选区／全屏可能包含控件”的说明，不遮盖录制像素。

## 验证范围

`qt_recording_window` 使用实际 Qt 控件和完整语言目录，验证选择值、按钮尺寸、
准备与收尾阶段、单调计时、首个停止意图、输出等待和重试生命期，并生成 PNG。
本地已实际构建运行并检查生成图像；编辑器和截图控件也通过共享工具栏变更后的
回归。该测试没有替代录屏后端，不证明真实捕获、音源、剪贴板持久化或屏幕拖动。
正式应用装配、两端真实桌面录制和 P09/P12 全量验收继续由对应服务及实测门槛
约束，不能仅据这个窗口或组件测试宣布录屏迁移完成。
