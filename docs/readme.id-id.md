# huhucapture

huhucapture adalah aplikasi tangkapan layar, anotasi, perekam layar, dan berbagi media untuk Windows dan Linux. Aplikasi ini mendukung gambar sematan, tangkapan gulir, GIF / MP4, kode QR, dan transfer LocalSend.

Unduh penginstal atau ZIP portabel lengkap untuk Windows x64, atau DEB atau AppImage untuk Linux amd64. Ekstrak seluruh ZIP Windows ke folder baru sebelum menjalankan aplikasi. Windows 10 1803 dapat menggunakan versi jembatan v0.0.6.
