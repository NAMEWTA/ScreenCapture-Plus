# huhucapture

huhucapture is a screenshot, annotation, screen recording and media sharing app for Windows and Linux. It includes pinned images, scrolling capture, GIF / MP4, QR recognition and LocalSend transfers.

Download the installer or complete portable ZIP for Windows x64, or the DEB or AppImage for Linux amd64. Extract the full Windows ZIP into a new folder before launching. Systems running Windows 10 1803 can use the older v0.0.6 bridge.
