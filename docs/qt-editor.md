# Qt 编辑组件的边界与交互合同

`src/ui/qt` 是 Windows 与 Linux 共用的正式编辑组件。它使用同一个
`EditorDocument<EditorShape>`，几何直接调用 `src/editor` 的九种工具模型，
没有另一份 Qt 专用的历史、编号或命中算法。原 Windows 适配器仍作为迁移回归基线；
组件可构建不等于整个 Qt 产品或 P07 已验收，阶段门槛见 [迁移边界](qt-migration.md)。

## 图像、文档和输入的所有权

载入一个图像创建一个文档边界。画布复制可能借用外部缓冲区的图像，并把 DPR 元数据
归一为 1；坐标和导出始终使用原图物理像素。已载入的画布拒绝第二次载入，防止异步
截图回调覆盖仍在编辑的数据。新的截图或贴图应创建新的窗口与文档。

图形由文档独占。窗口只能在历史回调规定的存活范围内借用图形。普通文字使用一个
共享 `QPlainTextEdit`，范围批注使用另一个共享备注输入框；批注列表只持有显示摘要。
正文和完整备注始终由形状模型保存。结束文字输入时先提交输入法、解除借用，再通过
历史 ticket 延迟清理空图形，旧失焦回调不能删除或结束另一个输入会话。

保留现有活动前缀历史：撤销与重做控制形状是否活动，移动、样式调整和文字修改仍是
对形状的就地修改。输入框获得焦点时，复制、删除、换行和撤销归输入框；备注中仍可
显式使用 Ctrl+S 保存。不能把输入框的 Ctrl+Z 转成删除整个批注。

## 普通文字的样式修正

旧 `ShapeText::setAttr()` 直接读取当时 `ToolSub` 的滑块值和颜色。选着矩形等工具
再点击已有文字时，文字可能继承矩形的 2px 线宽作为字号。Qt 组件修复这一污染：

- 进入或重新进入文字编辑时，读取 **Text 工具自己的最后一组设置**。
- 字号、颜色、Bold、Italic 的明确文字设置全部保留。Text 字号继续采用共享的
  10–60 逻辑像素范围，并在进入形状时按当前 DPR 转成原图像素一次。
- `setToolStyle(EditorTool::Text, ...)` 仍立即更新正在编辑的文字；改变其他工具的
  线宽不会改动文字字号。该修正不自动改变用户选中的绘制工具。
- 普通文字的 Bold 使用 `QFont::Bold`，对应旧 `DWRITE_FONT_WEIGHT_BOLD`。
  批注徽章继续使用单独的 SemiBold，不能把二者合并为一个字重。

## 指针、选中状态和缩放

工具顺序、44 DIP 点击区域与 24 DIP 图标保留。所有颜色、滑块范围和默认值来自
`ToolSettings`；旧 Windows 工具条也调用这份定义。共享 Qt 组件使用同一组已有图标
字体和批注矢量路径。图标字体加载失败时提供可读的本地化文字按钮，并通过
`iconFontAvailable()` 向宿主报告，不能把空字形视为图标加载成功。

普通编号与批注编号相互独立。普通编号仍取活动形状中的最大值加一；批注 ID 在一次
文档内只增不复用，取消、删除、撤销和清理重做分支都不会回收它。

新批注只在指针释放后聚焦备注输入。已有批注在按下时选中，移动或调整大小不抢走
画布焦点；需要打开右栏或重新适配视口时，等捕获结束再处理。新建过程失去捕获则
删除未完成区域，既有区域保留最后一个有效位置。选中批注的控制点在备注编辑期间
仍可见；正在拖动的 hover 控制点不进入绘制反馈。

收起批注栏会取消当前 Annotation 工具，恢复未选择画笔时的贴图拖动操作，保留全部
图形和备注。普通序号滚轮调整半径时暂时隐藏控制点，下次指针移动再显示；连续滚轮
保持同一目标，不能因控制点随半径移动就提前停止。仅移动旧序号不会覆盖当前工具
中为下一个序号选好的半径。

Ctrl+滚轮按 10% 改变图像缩放，并保持指针对应的原图位置。图像与 Qt 控件的 DPR
变换分开处理；窗口移动使用 Qt 原生移动请求，不在语言或 DPI 更新时重新居中。
实际混合 DPI、负坐标显示器和 Wayland 窗口策略仍需实体桌面验收。

## 控件文字与批注栏

编辑器控件使用系统字体，字号以 Qt 逻辑像素固定：普通控件 14、批注标题 16、
编辑区标题 13、输入框 15、提示 12。普通字重显式设为 Normal；标题和徽章单独
使用 DemiBold。原图里的普通文字仍按自己的源像素样式渲染，不受控件字体影响。
这保证同一份尺寸规范不会被 Windows 与 Linux 的默认 point 字号再次缩放。

批注栏提示按实际字体和可用宽度换行，使用同一 `AnnotationPanelGeometry` 为页脚
增长保留空间，不能覆盖列表、删除按钮或正文输入。极长自定义译文保留完整文本，
在最多 72 逻辑像素高的独立滚动区域中阅读；不通过缩小字号或截断来适配。

## 导出与宿主服务

窗口只生成最终图像快照，不自行实现第二份归档、文件命名、剪贴板或贴图服务。
宿主连接真实服务后，才分别启用 Archive、SaveAs、Clipboard、Pin 意图。未连接的
输出默认禁用。`outputRequested` 的图像已包含全部有效形状和完整备注，不是窗口抓图。

一次输出有一个单调 token。等待期间保留文档并锁定编辑；宿主在 GUI 线程调用
`completeOutput`，或通过带窗口上下文的 queued Qt 连接完成。失败和取消恢复编辑，
旧 token、重复回调和迟到成功均不能覆盖新状态或关闭窗口。关闭请求发生在输出期间
时发送取消请求，直到宿主完成取消前仍保留文档。宿主通过
`setCloseOnSuccessfulOutput` 区分完成截图与需要继续打开的贴图模式。

最终组合直接使用 `QtAnnotationRenderer` 的完整排版和预算检查，失败不替换已有
输出。原图位于左上角，导出不使用视口缩放。马赛克在手势结束后采样原图与之前的
活动形状，仅缓存局部区域；像素分块平均与旧适配器共用 `Core::mosaicPixels`。
橡皮擦恢复原图内容，不能以清成透明替代。

## 验证范围

`tests/qt/editor_component_tests.cpp` 驱动真实 Qt Widgets、输入事件、字体布局和
像素导出，检查九工具、文字与备注快捷键、历史与 ID、捕获丢失、控制点反馈、滚轮、
输出失败与取消、token、防止覆盖旧输出及原图坐标。PNG 证据来自真实渲染。
`tests/mosaic_pixels_tests.cpp` 在 Release 的 `NDEBUG` 条件下也保留全部断言。

上述组件测试不证明 Windows/Linux 安装、实际截图授权、剪贴板媒体服务装配、实体
中文输入法候选窗、双屏移动或最终性能已经通过。实际结果和必要门槛分别记录在
[验证边界](validation.md) 与 [迁移边界](qt-migration.md)，不能用事件合成代替实体
桌面验收，也不能仅因组件存在而移除旧生产适配器。
