# 局域网媒体互传

1. 在两台设备上打开 huhucapture，在设置中明确开启局域网共享，并选择可互相到达的网卡。设备列表支持刷新；组播不可用时可以输入接收设备的 IPv4 地址和端口。
2. 在发送端的媒体历史中找到一份截图或录屏，再选择局域网发送。核对接收设备证书指纹，初次发送或证书变化时需要明确确认。
3. 接收端逐次确认传输请求。任务窗显示传输进度，接收文件通过完整性和媒体检查后才进入历史。发生重名时保留已有文件。

关闭任务窗后，已确认的任务仍由应用处理。退出应用会停止网络服务。若连接、传输或落盘失败，任务显示实际结果，发送端原件继续保存在历史中。重新发送前可刷新设备并核对指纹。

当前自动化使用真实 TLS 连接和共享归档服务。实体设备间互传、不同网卡环境以及官方 LocalSend 客户端互操作以各自的运行记录为准。协议与错误语义见 [传输服务](transfer-service.md)，网卡、证书和配置状态见 [局域网控制层](lan-controller.md)。
