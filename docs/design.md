# 界面设计约定

## 采用的方向

设置和媒体历史采用用户指定的 [Apple 设计分析](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/DESIGN.md)，参考说明见 [对应 README](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/README.md)。参考的是字体层级、单一交互蓝、安静的中性色、留白和功能分组；这些规则适配原生 Windows 桌面窗口。

设置是高频操作界面。它使用分组卡片、固定导航与明确的控件状态，避免将网页宣传页的大幅标题与大片空白机械地搬入较小窗口。继续使用 Ling、DirectWrite 和 Windows 字体，不引入浏览器运行时或随程序分发 Apple 的专有字体。

## 颜色与文字

| 职责 | 约定 |
| --- | --- |
| 画布 | `#f5f5f7`，与白色内容区形成温和层次 |
| 内容卡片 | `#ffffff`，使用轻边界与留白区分分组 |
| 主文字 | `#1d1d1f`，避免低对比度正文 |
| 主要交互 | `#0066cc`；焦点使用清晰可见的蓝色边界 |
| 正文与设置标签 | 以 17 逻辑像素为基准 |
| 辅助说明 | 以 14 逻辑像素为基准，保持可读对比度 |
| 标题 | 通过字号、半粗体和空间建立层级，避免层层加重 |

虎虎图标和品牌插画保留自身的橘色与奶油色，规则见 [品牌资源](brand.md)。这些色彩不再决定整个设置页的背景、标签和选中状态；自动批注配色也独立于界面主题。

## 布局与交互

导航和内容形成稳定的两栏，页面内按用户任务分组。卡片内边距和组间距保持一致，正文与操作按钮对齐。常用控件具有足够的逻辑点击面积；增加字号时同步调整行高和控件高度。

设置页的基础标签使用单行布局，因此译文应保持简洁。长路径在界面中压缩显示，完整路径保留在打开目录按钮的提示和实际操作中。窗口高度较小时收紧内边距并隐藏辅助说明，主要设置项保持原有字号。语言选择使用 Windows 原生菜单处理 DPI、键盘与长列表滚动，媒体历史列表独立滚动和分页。切换页面、关闭窗口或点击外部时及时收起菜单，弹层的生命周期不超过拥有它的页面。

快捷键以独立键帽显示，编辑状态清楚，保留原有键盘录入行为。开关展示真实保存状态；目录操作明确指向当前归档位置。破坏性的历史清理采用二次确认，文案说明送入回收站的范围。

媒体列表中的图像是用户要找的内容。截图显示缩略图，视频显示封面和类型提示；封面加载失败仍保留文件名和操作入口。列表先保持可响应，再逐步补齐缩略图，避免为了封面同步打开所有视频。

## 后续扩展

新控件优先复用同页已有的颜色、字体和间距定义。不要为每项设置加新的强调色或装饰渐变。保留鼠标、键盘、DPI 和本地化的共同约束；新功能不能在默认字号下挤掉现有设置。

设计验收检查真实 Windows 窗口：中英文、长路径、100%–300% DPI、窗口边缘和弹层行为。源码常量符合此表不等于最终布局正确，具体证据按 [验证边界](validation.md) 记录。
